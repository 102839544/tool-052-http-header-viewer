# http-header-viewer 🚀

🌐 网页工具 - HTTP头信息查看器

## ✨ 功能特性

- 简单易用，界面友好
- 支持批量处理
- 开源免费

## 📦 安装

```bash
# 克隆仓库
git clone https://github.com/102839544/tool-052-http-header-viewer.git
cd tool-052-http-header-viewer

# 安装依赖
pip install -r requirements.txt
```

## 🚀 使用方法

```bash
python src/app.py
```

## 📖 功能说明

本工具提供 **HTTP头信息查看器** 功能，操作简单，适合日常使用。

## 🛠️ 技术栈

- Python 3.8+
- 跨平台支持
